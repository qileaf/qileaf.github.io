    Prototype scope

    This presentation version limits dropdown choices to: OCH, Emergency, Block 3, Block 4, Block 5, Block 6, Block 7, MRT Exit 6, MRT Exit 7, NCCS, Academia, SNEC, and NHS.

    • The map remains visible before and after route generation.
    • The blue route overlay appears only after Route Now is pressed.
    • The temporary direct pedestrian route from MRT Exit 6 into campus is shown as excluded, so it is never used by the routing engine.
    • Wheelchair shuttle links are only considered when the selected route starts or ends at MRT Exit 6, to avoid unrealistic campus-to-campus detours.
    • Distances, travel time, exact turns, slopes, lift status, door widths, and construction closures are placeholder values for stakeholder review.
